## サイト全体の修正方針

### 最重要課題：Googleインデックスへの登録

`site:goto-events.net` の検索結果が0件。サイトがGoogleに認識されていない可能性が高い。

**確認・対応事項**
- [ ] Google Search Consoleでインデックス状況を確認
- [ ] robots.txtに `Disallow: /` などのブロック設定がないか確認
- [ ] XMLサイトマップをSearch Consoleに送信
- [ ] ページのインデックスリクエストを手動実行
- [ ] noindexメタタグが設定されていないか全ページ確認

---

### 修正方針①：Schema.orgのサイト名を修正

**現状（問題）**
```json
{"@type":"WebSite","name":"五島福江島への航路欠航情報"}
```
**修正後**
```json
{"@type":"WebSite","name":"五島列島のお役立ち情報（交通・不動産・イベント等）","url":"https://goto-events.net/"}
```
→ Cocoonテーマ設定またはfunctions.phpで修正。サイト名がGoogleのナレッジパネルや検索結果に影響する。

## 個別ページの改修方針

### 【欠航情報ページ】page_id=104 ★★★★★ 優先度：最高

**強み（維持する点）**
- 毎日08:07の自動更新は継続
- 九州商船・野母商船・ANA/ORCを一元化した横断まとめの構成は維持
- 16語のmeta keywordsは充実しており、「欠航 代替手段」「遅延」など実用的キーワードもカバー済み

**修正が必要な点**

1. **titleタグとOGP titleの不一致を解消**
   - titleタグ（検索結果表示用）：`【毎日更新】五島の欠航情報｜ジェットフォイル・フェリー・飛行機の運航状況`
   - OGP title（SNSシェア用）：`【最新】福江島行き交通機関 欠航情報と代替ルートまとめ`（現状維持でも可）

2. **meta keywordsに「五島 欠航」単体を追加**
   - 現状は「五島福江島」「五島 福江 欠航」が主体で「五島 欠航」単体が未設定

3. **「欠航の基準」解説コンテンツを追加**（H2セクションとして）
   - 波高・風速の目安
   - ジェットフォイルとフェリーで欠航基準が違う点
   - 飛行機（鬼岳が見えなくなると欠航）

4. **「欠航したら払い戻しは？」Q&Aセクションを追加**
   - 競合（九州商船FAQ、STLOCAL記事）が取っているロングテールキーワードを獲得

5. **更新タイムスタンプを目立たせる**
   - 「本日 2026/03/31 08:07 更新」をページ最上部に表示

### 【求人情報ページ】page_id=384 ★★★★☆ 優先度：高

**強み（維持する点）**
- 毎日05:00自動更新・100件表示の仕組みは最大の差別化ポイント
- 「五島市の仕事の傾向」「移住支援制度」の解説セクションは有効
- title/OGP titleが一致しており、SNSシェア時のブレなし

**修正が必要な点**

1. **meta keywordsを6語→15語以上に増強**（最重要）
   - 追加：`Iターン, 五島 医療 求人, 五島 介護 求人, 五島 看護師, 五島 農業 求人, 五島 漁業, 五島 パート, 五島市 転職, 長崎 離島 求人`

2. **求人傾向セクションに職種別の深掘りを追加**
   - 医療・福祉（なぜ増加中か）
   - 農業・漁業（季節求人の特徴）
   - 観光・宿泊（繁忙期の求人動向）
   → 「五島 医療 求人」「五島 農業 求人」などのロングテールキーワードを本文内に自然に含める

3. **「五島で働く給与の目安」コンテンツを追加**
   - ハローワークデータを集計した平均時給・月収の目安を掲載
   - 「五島 給与 相場」「五島 賃金」等のキーワードを獲得

4. **移住支援制度セクションの充実**
   - 具体的な補助金額・条件を明記（外部リンクのみでなく自サイト内で解説）

### 【不動産情報ページ】page_id=143 ★★★★☆ 優先度：高

**強み（維持する点）**
- 毎朝「前日差分」のみを抽出する独自の更新方式は最大の差別化ポイント
- 10業者・件数の透明な掲載は信頼性が高い
- 「物件探しを失敗しないコツ」「内見チェックポイント」など実用コンテンツあり
- 免責事項（仲介を行わない）の明記は適切

**修正が必要な点**

1. **「移住」をmeta keywordsの先頭付近に移動**
   - 現状：末尾 → 移住検討者への訴求強化

2. **家賃・物件相場の目安コンテンツを追加**（H2セクションとして）
   - 実際の掲載データ（成美企画25件・ラビーネット29件等）を基に相場感を提示
   - 「五島 賃貸 相場」「福江島 家賃」などのキーワードを獲得

3. **空き家バンクの利用ガイドを拡充**
   - 現状：外部リンクのみ
   - 追加：空き家バンクの利用手順・対象条件・メリット/デメリットの解説
   - 「五島 空き家バンク 使い方」キーワードの獲得を狙う

4. **各業者の特徴を一言で説明する**
   - 現状：業者名+件数のみ
   - 追加：各業者の得意分野（例：アース企画→リノベーション物件が強み、くらす企画→移住者向け）

5. **市営住宅情報を拡充**
   - 現在は外部リンク1本のみ
   - 五島市の市営住宅の申込時期・条件・家賃水準をサイト内で解説

### 【イベント情報ページ】page_id=282 ★★★☆☆ 優先度：中

**強み（維持する点）**
- FullCalendarによるインタラクティブなカレンダーUIは他の競合にない機能
- エリア別（9エリア）・カテゴリ別（8種）・キーワード検索の組み合わせは強力
- 「イベント重複防止」という独自の設立理念は差別化ポイント
- イベント掲載希望ページ（p=330）で情報収集の仕組みを持つ

**修正が必要な点**

1. **titleタグに年号を追加**
   - 現状：`五島市イベントカレンダー｜開催日・エリアで検索`
   - 修正：`五島市イベントカレンダー2026｜開催日・エリア・カテゴリで検索`
   - 毎年更新することで「五島 イベント 2026」「五島 イベント 2027」を継続獲得

2. **meta keywordsから「ながさき旅ネット」「五島市公式サイト」を削除**
   - 競合サイト名をキーワードに含めることは不適切
   - 代替：`五島 イベント 2026, 五島椿まつり, バラモンキング, バラモン凧, 五島 マラソン`

3. **主要イベントの説明コンテンツを追加**（H2セクションとして）
   - カレンダー+テキストコンテンツの組み合わせでSEOクローラーへの評価向上
   - 対象：五島椿まつり・バラモン凧揚げ大会・バラモンキング・魚津ヶ崎コスモスまつり
   - 各イベントの概要・開催時期・見どころを200〜300字で掲載

4. **欠航情報ページへの内部リンクを追加**
   - 「イベント当日の船・飛行機の運航状況は欠航情報ページでご確認ください」
   - サイト全体の回遊性向上＋欠航情報ページのPV増加に貢献

5. **PV増加のための導線改善**
   - 現状PV：全体38（非常に少ない）
   - トップページの「週刊求人動向」「不動産動向」と並んでイベント情報の最新記事を表示
   - SNS投稿（X・Facebook）でイベント情報を定期配信
