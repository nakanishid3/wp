# goto-events.net 改善方針

## サイト概要と現状評価

- **サイト名**: goto-events.net
- **対象地域**: 長崎県五島市（五島列島）
- **サイト特性**: 五島市の生活情報ハブサイト（欠航情報・求人情報・不動産情報・イベント情報を集約）
- **現状評価**: 各ページが情報のリンク集にとどまる傾向があり、オリジナルコンテンツが不足。SEO競合に対してコンテンツ量と深度で劣っている

---

## サイト全体の修正方針

### 1. サイトポジショニングの明確化
**「五島に関わるすべての人のための生活情報ハブ」**

- 観光客・移住検討者・島民・帰省者など多様なユーザーに向けた情報を提供
- 行政公式サイトや観光協会が取りこぼしている「生活リアル情報」に特化
- 各ページが相互にリンクし、サイト全体での回遊を促進する構造を構築

### 2. コンテンツ品質の向上（全ページ共通）
- **リンク集→コンテンツサイトへの転換**: 外部リンクのみでなく、オリジナルの解説・ガイドコンテンツを追加
- **Q&Aセクションの新設**: 各ページに「よくある質問」セクションを追加し、ロングテールキーワードを獲得
- **更新頻度の向上**: コンテンツの定期更新をスケジュール化（検索エンジンからの評価向上）

### 3. 技術的SEOの改善（全ページ共通）
- **タイトルタグの最適化**: 「ページ名｜五島市 キーワード1 キーワード2」の形式に統一
- **メタディスクリプションの最適化**: 各ページの価値と主要キーワードを含む120〜150文字で設定
- **構造化データの実装**: FAQページスキーマ・記事スキーマを実装してリッチスニペット獲得を狙う
- **内部リンクの強化**: 関連ページ（例：求人情報↔不動産情報↔イベント情報）の相互リンク設置
- **ページ表示速度の改善**: 画像最適化・キャッシュ設定

### 4. UX・モバイル対応の改善（全ページ共通）
- **スマートフォン最適化**: 緊急性の高い欠航情報は特に、スマホで素早く情報取得できるUI
- **目次・アンカーリンクの設置**: 長いページで目的の情報に素早くアクセスできるナビゲーション
- **CTAの明確化**: 各ページで次のアクション（関連ページへの誘導・お問い合わせ等）を明示

## 個別ページの改修方針

### 【欠航情報ページ】(page_id=104)

#### 改修の優先度: ★★★★★（最高）
欠航情報は緊急性の高い情報であり、悪天候時のアクセス急増が見込まれる。短期間でのトラフィック増加が最も期待できるページ。

#### 具体的な改修内容

**SEO改善**
- タイトル: `五島の欠航情報｜船・飛行機の運航状況まとめ【随時更新】`
- ディスクリプション: `五島行きの船（九州商船・野母商船・五島産業汽船）と飛行機（ORC・ANA・JAL）の欠航・運航状況を1ページでまとめて確認。欠航時の対処法も解説。`
- H1: 「五島の欠航情報｜船・飛行機の運航状況を一括確認」

**コンテンツ追加**
1. 各交通機関の運航状況リンク集（既存を整理・視覚化）
2. **「欠航の基準は？」解説セクション**: 波高・風速の目安、ジェットフォイルとフェリーの欠航基準の違い
3. **「欠航したら？対処法ガイド」セクション**: 船↔飛行機の代替手段、払い戻し方法、当日の対応方法
4. **「欠航情報はいつわかる？」FAQ**: 台風時・通常時の欠航決定タイミング
5. 欠航が多い時期（台風シーズン・冬の時化時期）の情報

**キーワードターゲット**
- 主: 「五島 欠航情報」「五島 運航状況」
- 副: 「五島 欠航 したら」「五島 欠航 いつわかる」「九州商船 欠航 確認」「五島 台風 船」

### 【求人情報ページ】(page_id=384)

#### 改修の優先度: ★★★★☆（高）
毎日自動更新という強みを持つが、競合との差別化コンテンツが不足。移住者の「仕事探し＋移住情報」のニーズを同時に満たすコンテンツを追加。

#### 具体的な改修内容

**SEO改善**
- タイトル: `五島市の最新求人情報｜毎日更新・移住・Uターン・Iターン向け仕事探し`
- ディスクリプション: `五島市のハローワーク最新求人を毎日更新。医療・福祉・観光・農業など全業種掲載。移住・Uターン・Iターン検討中の方の仕事探しに。`
- H1: 「五島市の最新求人情報」

**コンテンツ追加**
1. 求人一覧（既存：毎日自動更新）
2. **「五島市の仕事事情」解説セクション**: 業種別傾向・医療福祉が増加中などのデータ
3. **「五島で働く前に知っておくこと」ガイド**: 給与相場・ダブルワーク文化・求人の特徴
4. **職種別ショートカットリンク**: 医療/介護/農業/観光/建設などカテゴリ別に誘導
5. **Q&Aセクション**: 「未経験でも働ける仕事はある？」「移住したら仕事が見つかる？」等
6. 不動産情報・イベント情報への内部リンク（移住検討者の生活全体をサポート）

**キーワードターゲット**
- 主: 「五島市 求人」「五島 移住 仕事」「五島 求人 最新」
- 副: 「五島 求人 医療」「五島 求人 介護」「五島 Uターン 求人」「五島 ハローワーク」

## 改修の優先順位と実施スケジュール

| 優先度 | ページ | 理由 |
|--------|--------|------|
| 1位 | 欠航情報 | 緊急性高・差別化しやすい・即効性あり |
| 2位 | 求人情報 | 既存強み（自動更新）を活かせる・移住需要が高い |
| 3位 | 不動産情報 | 移住需要に対応・求人と相乗効果 |
| 4位 | イベント情報 | 競合が多いが年次更新で継続的に改善 |

---

## 内部リンク戦略（サイト全体の回遊促進）

```
欠航情報 ←→ イベント情報（イベント当日の移動確認）
求人情報 ←→ 不動産情報（移住時の仕事+住まいをセット）
不動産情報 ←→ イベント情報（移住後の生活・コミュニティ）
全ページ → トップページ（五島の総合情報ハブとして機能）
```

**推奨内部リンク文言例**
- 欠航情報→イベント情報: 「イベント参加時は事前に欠航情報もご確認ください」
- 求人情報→不動産情報: 「五島での住まいについては不動産情報もご覧ください」
- 不動産情報→求人情報: 「五島での仕事探しは求人情報ページもご活用ください」
